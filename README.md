# Luis Avatar 3D 🎨

Avatar 3D realista para metaverso y redes sociales. Creado con React, Three.js y WebGL.

## Características

✨ Avatar 3D realista basado en características personales
🔄 Rotación e interactividad completa
🎬 Animaciones suaves
💾 Exportable a formatos GLB/GLTF para metaversos
🌐 Compatible con Decentraland, Spatial y otros metaversos
📱 Responsive y optimizado para web

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm start
```

La aplicación se abrirá en `http://localhost:3000`

## Build para Producción

```bash
npm run build
```

## Características del Avatar

- **Cabello**: Rizado oscuro
- **Barba**: Realista
- **Ropa**: Traje negro profesional
- **Accesorios**: Maletín marrón, corbata azul
- **Iluminación**: PBR (Physically Based Rendering)

## Controles

- **Mouse**: Arrastra para rotar el avatar
- **Rueda del ratón**: Zoom in/out
- **Botones**: Cambiar pose/animación

## Exportación a Metaverso

Para exportar tu avatar:

1. Haz clic en "Exportar GLB"
2. Carga el archivo en tu metaverso favorito
3. ¡Disfruta tu avatar 3D!

## Tech Stack

- React 18
- Three.js r128
- React Three Fiber
- Drei (helpers)
- WebGL
